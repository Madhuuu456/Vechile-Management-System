ℹ️ About Madhu

Vehicle Service Management System

What is this website?

Madhu helps a vehicle service centre keep all its work in one place: customers, their vehicles, the services offered, bookings and payments. All data is saved in a MySQL database.

How to use it (in this order)

  1. Customers - add the customer's name and phone number.
  2. Vehicles - add the customer's vehicle and choose the owner.
  3. Services - check the services and prices (some are added for you).
  4. Bookings - choose a vehicle and a service, then set the status.
  5. Payments - choose the booking and record the payment.
  6. Dashboard / Reports - see totals and summaries.

Technology used

HTML, CSS and JavaScript (front end) · Node.js with Express.js (back end) · MySQL (database).
